Privacy policy

Austin HA, a private Home Assistant installation. Last updated September 28, 2026.

What this application is

Austin HA is a Home Assistant server used by a single household to automate its own home. It connects to Google's Smart Device Management API so that the household's own Nest devices (thermostats, cameras, doorbells) can be seen and controlled from Home Assistant.

What data it accesses

With the owner's permission, granted through Google's sign-in screen, the application reads device state (for example, temperature, mode, and camera events) and sends commands (for example, changing a thermostat setpoint) for the devices the owner chooses to share. It does not access any other Google account data.

Where the data goes

Device data is received and stored only on the Home Assistant server inside the household's home network. It is not sent to any third party, not sold, not used for advertising, and not shared outside the household. The household members are the only users.

Retention and deletion

Device history is kept on the local server for as long as the owner chooses and can be deleted at any time. Access can be revoked at any time from the Google account permissions page or from Google's Partner Connections Manager, after which the application can no longer read or control the devices.

Contact

Questions about this policy go to the owner of the installation at the support email shown on the Google sign-in screen.
