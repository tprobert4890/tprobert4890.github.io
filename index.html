Austin HA

A private Home Assistant installation for one household.

This page exists so that Google can display an application name and home page on its sign-in screen. "Austin HA" is the Home Assistant server running in the Robertson home. It uses Google's Smart Device Management API to read and control the household's own Nest devices.

It is not a product or a service. Nobody outside the household can sign in, and nothing is offered to the public.
